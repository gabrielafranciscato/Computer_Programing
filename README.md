## Labs and Activities

### Python Basics

Activities include:

- Creating and using variables
- Working with integers and floats
- Performing arithmetic calculations
- Using strings and Boolean values
- Converting between data types
- Using `round()` and `abs()`

### Operators

Practice with Python operators including:

- Addition `+`
- Subtraction `-`
- Multiplication `*`
- Division `/`
- Floor division `//`
- Modulus `%`
- Exponentiation `**`
- Comparison operators
- Boolean operators (`and`, `or`, `not`)

### Conditional Statements

Activities using conditional logic to:

- Check whether a number is even or odd
- Check positive and negative numbers
- Compare values
- Find the largest number
- Make decisions using `if`, `elif`, and `else`

### Loops

Practice using loops to:

- Repeat operations
- Print sequences of numbers
- Calculate totals
- Create programs that continue until the user chooses to exit

### Functions

Function exercises include:

- Calculating the square of a number
- Calculating the factorial of a number
- Using parameters
- Returning values from functions

### Algorithms, Pseudocode and Flowcharts

Activities include designing solutions before writing Python code.

Examples include:

- Calculating the average of numbers
- Checking whether a number is even or odd
- Finding the largest of multiple numbers
- Pass or fail grading

Features explored include:
